FAQ

Questions? Answered.

Is YTGet really free?

Yes. YTGet is fully open source under its GitHub license — no ads, no paywalls, no tracking.

Do I need to install Python or FFmpeg?

No. Every release ships with everything bundled. Just download, extract (or install) and run.

Which sites are supported?

Anything yt-dlp supports — YouTube, YouTube Music, SoundCloud, Vimeo, TikTok, Instagram, X, Twitch and many more. Spotify links are handled via spotDL.

How do I keep yt-dlp up to date?

Use Help → Check yt-dlp Update from the menu bar. The built-in update manager handles the rest.

Something went wrong — where are the logs?

Open Help → Open Logs Folder. Attach ytget.log and crash.log when you open an issue on GitHub.
