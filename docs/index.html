Getting started

About two minutes, start to finish.

  1. Download and run the installer. Windows may show a "unknown publisher" warning because the app is not code-signed - choose More info then Run anyway.
  2. Let it fetch its tools. On first launch YTGet downloads yt-dlp and FFmpeg for you. No manual setup.
  3. Paste a link into the box and press Fetch to see the title, duration and available formats.
  4. Pick a format - a video resolution, or MP3 / FLAC / M4A for audio - and click Add to queue.
  5. Press Start. Files land in your chosen download folder; right-click any finished item to open it or show it in Explorer.

Tip: open Preferences to set your download folder, naming template, subtitle languages, the clipboard watcher and the scheduler. Everything is remembered between sessions.

Questions

Is YTGet free?

Yes - completely free and open source under the MIT licence. No ads, no accounts, no telemetry.

Why does Windows warn me about the installer?

The app is not code-signed yet, and code-signing certificates are expensive for a free project. Click More info then Run anyway. You can verify the file first using the SHA-256 checksum published with every release.

Do I need to install Python, yt-dlp or FFmpeg?

No. The Windows build is self-contained, and YTGet downloads and updates yt-dlp and FFmpeg by itself.

Where do my files go?

Wherever you choose in Preferences - by default your Downloads folder. Settings and logs live in %LOCALAPPDATA%\YTGet.

Does it work on macOS or Linux?

Yes, from source: pip install ytget-gui then run ytget-gui. Only Windows gets a prebuilt installer today.

Can I download a private or paid video?

Only content you are allowed to access. YTGet can use your browser cookies for things you have legitimately purchased or subscribed to - please respect each site's terms and the rights of creators.

How do I report a bug or ask for a feature?

Open an issue on GitHub. Including the link you used and a copy of the log helps a lot.
